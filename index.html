        🏆 المشروع النهائي
      

      
المشروع النهائي

      
ابنِ موقع ويب كاملاً باستخدام HTML وCSS وJavaScript ونشره على الإنترنت

    


    
    

      

        📋 متطلبات المشروع
      

      

        
◆ موقع متعدد الصفحات (3 صفحات على الأقل)

        
◆ تصميم متجاوب يعمل على الموبايل والديسكتوب

        
◆ استخدام HTML Semantic بشكل صحيح

        
◆ تنسيق CSS احترافي مع Flexbox أو Grid

        
◆ إضافة تفاعل باستخدام JavaScript

        
◆ رفع الكود على GitHub

        
◆ نشر الموقع على GitHub Pages أو Netlify

        
◆ مشاركة الرابط الحي ورابط المستودع

      

    


    
    

      

        🗺️ خطوات التنفيذ
      

      

        

          
1

          

            
اختر فكرة المشروع

            
اختر موضوع الموقع — محفظة شخصية، موقع شركة، متجر بسيط، مدونة، أو أي فكرة إبداعية.

          

        

        

          
2

          

            
ابنِ هيكل HTML

            
أنشئ ملفات HTML لكل صفحة مع البنية الصحيحة والعناصر الدلالية.

          

        

        

          
3

          

            
نسّق بـ CSS

            
أضف تصميماً احترافياً — ألوان، خطوط، تخطيط Flexbox/Grid، وتجاوب.

          

        

        

          
4

          

            
أضف JavaScript

            
أضف تفاعلاً — قوائم متحركة، تبديل أوضاع، نماذج، أو أي وظيفة تفاعلية.

          

        

        

          
5

          

            
ارفع على GitHub

            
أنشئ مستودعاً وارفع كودك كاملاً مع commits واضحة.

          

        

        

          
6

          

            
انشر الموقع

            
فعّل GitHub Pages أو ارفع على Netlify — وشارك الرابط الحي!

🐙 Git & GitHub

      
تعلم إدارة الكود ومشاركته والتعاون مع الآخرين

    


    

      
      
      
    


    
    

      

        
ما هو Git؟

        

          Git هو نظام تحكم في الإصدارات (Version Control System). يتتبع كل التغييرات التي تجريها على ملفاتك، ويتيح لك العودة لأي نقطة سابقة في مشروعك. فكر فيه كـ "سجل كامل لتاريخ مشروعك".
        

      

      

        
أوامر Git الأساسية

        

          

            
1

            

              
إنشاء مستودع جديد

              
في مجلد مشروعك، نفّذ هذا الأمر لتهيئة Git

              git init
            

          

          

            
2

            

              
إضافة الملفات للـ Staging

              
أضف الملفات المحدد لها commit

              git add .
              git add index.html
            

          

          

            
3

            

              
إنشاء Commit

              
احفظ التغييرات مع رسالة توضيحية

              git commit -m "Add homepage structure"
            

          

          

            
4

            

              
عرض حالة المستودع

              
تحقق من الملفات المعدّلة وحالة الـ Staging

              git status
            

          

          

            
5

            

              
عرض سجل الـ Commits

              
اعرض تاريخ كل التغييرات

              git log --oneline
            

          

        

      

    


    
    

      

        
ما هو GitHub؟

        

          GitHub هو منصة تستضيف مستودعات Git على الإنترنت. يتيح لك مشاركة كودك، التعاون مع المطورين الآخرين، وعرض أعمالك. امتلاك حساب GitHub ضروري لأي مطور ويب.
        

      

      

        
رفع مشروعك على GitHub

        

          

            
1

            

              
أنشئ حساباً على GitHub

              
اذهب إلى github.com وأنشئ حسابك المجاني

            

          

          

            
2

            

              
أنشئ مستودعاً جديداً

              
اضغط على "+" في الزاوية العلوية ثم "New repository"

            

          

          

            
3

            

              
اربط مشروعك بـ GitHub

              git remote add origin https://github.com/username/repo.git
            

          

          

            
4

            

              
ارفع الكود

              git push -u origin main
            

          

        

      

    


    
    

      

        
ما هو Deployment؟

        

          النشر (Deployment) هو عملية جعل موقعك متاحاً للجميع على الإنترنت. للمواقع الثابتة (HTML/CSS/JS) يمكنك النشر مجاناً باستخدام GitHub Pages أو Netlify.
        

      

      

        
🌐 GitHub Pages (مجاني)

        

          

            
1

            

              
ارفع مشروعك على GitHub

              git push origin main
            

          

          

            
2

            

              
فعّل GitHub Pages

              
اذهب إلى Settings → Pages → Source → Deploy from branch → main → Save

            

          

          

            
3

            

              
موقعك حي الآن! 🎉

              
سيكون متاحاً على: https://username.github.io/repo-name

            

          

        

      

      

        
⚡ Netlify (بديل سهل)

        

          اذهب إلى netlify.com وفقط اسحب مجلد مشروعك وأفلته — وسيكون موقعك حياً فوراً!

❓ الأسئلة الشائعة

      

        

          

            هل أحتاج خلفية برمجية مسبقة؟
            ▼
          

          
لا، الكورس مصمم للمبتدئين الكاملين. سنبدأ من الصفر ونبني المعرفة خطوة بخطوة.

        

        

          

            ما البرامج التي أحتاجها؟
            ▼
          

          
كل ما تحتاجه هو: VS Code (محرر مجاني)، متصفح Chrome أو Firefox، وحساب GitHub مجاني. كل هذه مجانية!

        

        

          

            هل يمكنني الوصول للمحاضرات في أي وقت؟
            ▼
          

          
نعم، يمكنك الوصول لجميع المواد المتاحة في أي وقت من حسابك. المحاضرات تُضاف تدريجياً بحسب جدول الكورس.

        

        

          

            كيف أسلّم المهام؟
            ▼
          

          
من صفحة كل محاضرة، أضف رابط مشروعك (GitHub أو أي رابط مباشر) في خانة التسليم واضغط "تسليم المهمة".

        

        

          

            ماذا بعد إنهاء الكورس؟
            ▼
          

          
بعد إنهاء الكورس، ستكون قادراً على بناء مواقع ويب كاملة ونشرها. المشروع النهائي سيكون معرضاً حقيقياً لمهاراتك.

        

        

          

            هل الكورس مجاني؟
            ▼
          

          
التسجيل في المنصة مجاني. للاستفسار عن تفاصيل الكورس، تواصل مع المدرب مباشرةً.
