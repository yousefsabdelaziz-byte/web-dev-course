🐙 Git & GitHub
تعلم إدارة الكود ومشاركته

    

      
      
      
    

    

      
ما هو Git؟
Git هو نظام تحكم في الإصدارات. يتتبع كل التغييرات على ملفاتك ويتيح لك العودة لأي نقطة سابقة.

      

        
أوامر Git الأساسية

        

          
1
إنشاء مستودع
git init

          
2
إضافة الملفات
git add .

          
3
إنشاء Commit
git commit -m "message"

          
4
عرض الحالة
git status

        

      

    

    

      
ما هو GitHub؟
GitHub منصة تستضيف مستودعات Git على الإنترنت.

        

          
1
أنشئ حساباً
اذهب إلى github.com

          
2
أنشئ Repository
git remote add origin https://github.com/user/repo.git

          
3
ارفع الكود
git push -u origin main

        

      

    

    

      
GitHub Pages (مجاني)

        

          
1
ارفع على GitHub
git push origin main

          
2
فعّل GitHub Pages
Settings → Pages → Source → main → Save

          
3
موقعك حي! 🎉
https://username.github.io/repo
